# 知行 GTD

思源笔记插件：在日记里用 `@GTD` 收集，安排到四象限，用时间块推进下一步，并管理日常习惯。

> 安装目录和数据目录仍为 `task-secretary`，升级不会丢失已有习惯和设置。

## 导航

主侧栏只有四个工作区：

- **收件箱**：新收集、尚未安排的事项；冷藏是它的一个筛选状态。
- **任务**：所有已安排任务，内部切换 **列表 / 四象限 / 时间线**。点铅笔打开统一的「任务设置」，可同时修改标题、类型、截止时间、四象限、执行时间块和提醒。
- **习惯**：每日打卡与连续记录。
- **知识**：`@知识` 的待归档内容。

刷新和全屏按钮固定在右上角，不再占用导航位置。

## 工作流

1. **收集**：在今天的日记里写一条任务，并在末尾加上 `@GTD`。
2. **安排**：打开右侧「知行 GTD」→ 收件箱，逐条选择四象限。
3. **执行**：四象限只显示已安排任务；完成卡片会推进下一步。
4. **排期**：把任务从时间线的「待排期」栏拖到时间格，形成时间块。
5. **习惯**：习惯独立于任务，每天重置，支持打卡、连续天数和番茄钟。

## 触发词分流

在日记里写内容时，用末尾触发词决定它去哪：

| 触发词 | 去向 | 处理方式 |
| --- | --- | --- |
| `@GTD` | 收件箱 | 等待安排成任务 |
| `@知识` | 知识待归档 | 选择笔记本和文档后归档 |
| `@阅读` / `@以后` | 冷藏池 | 暂时存放，之后再安排或归档 |
| 无标签的 `- [ ]` 任务项 | 收件箱 | 默认按 @GTD 处理 |

只有未完成的任务列表项会在无标签时进入收件箱；普通段落没有触发词不会被自动收集。安排、归档、冷藏都只写块属性，不改日记原文。

## 收集格式

单步任务：

```markdown
- [ ] 写完插件说明 @GTD
```

多步任务用嵌套任务列表，插件会把第一个未完成子块作为下一步行动：

```markdown
- [ ] 上线知行 GTD @GTD
    - [ ] 修复保存失败
    - [ ] 写使用说明
```

- 只有日记中带 `@GTD` 的内容会进入收件箱。
- 代码块和行内代码里的 `@GTD` 会被忽略。
- 已完成的 `[X]`、已安排、已归档的内容不会重复出现。
- 普通段落也可以带 `@GTD`，按单步任务处理；多步请使用嵌套任务列表。

## 收件箱

收件箱有三种来源：

- **日记**：最近 N 天（默认 30 天）日记中未安排的 `@GTD` 块。
- **指定**：在设置中指定一个笔记本和/或一篇文档，持续收集其中的 `@GTD`。
- **旧任务**：工作区里尚未安排的任务块，避免升级后任务丢失。

顶部筛选可以切换「全部 / 日记 / 指定」，存在旧任务时会出现「旧任务」。

年龄提示：超过 24 小时变黄，超过 48 小时变红。如果内容包含 URL 会显示 🔖 提示，长文本会显示 📖 提示。每条记录有三个出口：

- **安排**：进入四象限，成为任务。
- **知识**：选择笔记本和文档，复制内容归档。
- **冷藏**：移入冷藏池，暂时不处理。

点「安排」后：

- 原文只读展示；
- 下一步行动自动取第一个未完成子块（单步任务可修改）；
- 四象限必选；
- 确认后只写块属性，不改写日记原文。

安排状态使用块属性：`custom-gtd-clarified`、`custom-gtd-quadrant`、`custom-gtd-next-action`。

## 知识待归档

带 `@知识` 的内容不会进入任务收件箱，而是出现在「知识」工作区。点「归档」后：

1. 选择分类笔记本；
2. 选择该笔记本下的目标文档；
3. 插件把内容复制到目标文档；
4. 日记原文写入归档属性，从待归档列表消失。

## 冷藏池

带 `@阅读` 或 `@以后` 的内容，以及在收件箱点「冷藏」的内容，会进入收件箱的「冷藏」筛选状态。冷藏池支持：

- **去安排**：把它变成四象限任务；
- **归档**：存为知识。

冷藏不会制造任务焦虑，也不会出现在时间线。

## 四象限

四象限只显示 `clarified`、有象限归属且未归档的任务：

- **重要且紧急 / 立即做**
- **重要不紧急 / 计划做**
- **不重要但紧急 / 委托做**
- **不重要不紧急 / 少做**

每张卡片显示主任务、灰色「下一步行动」和剩余步骤数。完成按钮：

- 有子任务：完成下一步，卡片原地刷新；
- 没有子任务：完成任务；
- 全部步骤完成：主任务标记完成并归档。

四象限没有 `+` 新建按钮；收集入口只有日记里的 `@GTD`。卡片可拖到其他象限，拖拽只更新象限属性，不再改性价比或日期。

**四象限与性价比**：四象限决定这件事属于哪一类；性价比决定同一类里值不值得做、先做哪个。高性价比显示为绿色，一般为黄色，低性价比为灰色。性价比不会改变象限归属，也不会和象限互相覆盖。

## 时间线

时间线只显示已安排任务，采用连续时间轴（06:00–24:00）：

- **待排期**栏按四象限分组，显示没有时间块的任务；
- 从待排期栏拖到时间格，默认生成 60 分钟时间块；
- 直接拖动时间块可改开始时间，时长保持不变，15 分钟吸附；
- 窄屏或触摸设备可先点选任务，再点时间格；
- 时间块上可完成下一步、启动番茄钟或移出时间线。

时间块保存在块属性中：`custom-gtd-plan-date`、`custom-gtd-plan-start`、`custom-gtd-plan-end`。

### 全窗口放映

桌面端可把今天的时间线变成全窗口黑底放映，用鼠标控制连续滚动：

- 时间线右上角点「▶ 放映」进入，按 `Esc` 退出；
- 悬停暂停，滚轮浏览，按住空白处拖动定位；
- 点击任务可选择打开任务、完成下一步或开始番茄；
- 底部可切换 0.5× / 1× / 2× 速度；
- 自动记住速度和位置，下次进入继续；
- 设置中可开启「每日首次启动自动放映」，每天第一次启动时自动进入一次。

## 习惯

习惯在同一个 Dock 的「习惯」标签中，独立于任务系统：

- 支持每天、每周、每月、每年、艾宾浩斯、无固定频率；
- 支持打卡次数、专注时长或任一达成；
- 支持连续天数、补打卡、放弃习惯；
- 支持番茄钟和正计时；
- 文档内仍可插入习惯打卡嵌入块（命令 `⇧⌘H` 或习惯面板右键）。

习惯数据保存在插件的 `habits.json`，不会写入笔记。

## 番茄钟

- 任务卡片和时间块右侧的 🍅 可启动番茄钟。
- 默认专注 25 分钟、休息 5 分钟，可在设置中修改。
- 思源最小化时显示桌面置顶迷你倒计时。
- 从四象限或时间块启动时，专注结束会完成当前「下一步」，再记录一条 `🍅 专注了 N 分钟`。
- 白底大字提示「番茄结束 / 休息结束」。

## 提醒

- 任务设置了计划时间或截止时间后，会按设置的提前分钟数提醒一次；如果提前时间已经过去，则在到点提醒。
- 需要正好到点提醒时，把提醒设为「准时提醒」；需要关闭时设为「不提醒」。
- 每次提醒同时触发思源的右下角弹窗和系统通知。
- 单个任务可以把提醒设为「到点」「关闭」；习惯可以设置提醒时间。
- 系统通知需要在操作系统中允许思源发送通知。

## 设置

- **收件箱扫描天数**：默认 30 天。
- **番茄钟专注 / 休息分钟数**。
- **指定笔记本 / 指定文档**：持续收集指定范围里的 `@GTD`、`@知识`、`@阅读`、`@以后`。
- **提醒、默认日程时间、ICS 导出、云上传**：保留原有功能；ICS 只导出已安排且未归档的任务。
- 访问密钥 Secret 仍从思源「设置 → 密钥和变量」读取，不写入配置文件。

## 数据与兼容

- 不删除、不迁移现有任务块；旧任务进入收件箱等待安排。
- 现有 `custom-task-*` 属性、习惯数据、番茄钟数据保留。
- 新属性均以 `custom-gtd-*` 开头。
- 已完成任务通过 `[X]` 或 `custom-gtd-done` 标记；归档通过 `custom-gtd-archived`。

## 开发

```bash
pnpm install
pnpm run check
pnpm run build
```

生产构建输出到 `dist/`，将内容复制到工作区插件目录：

```text
<workspace>/data/plugins/task-secretary/
```

重启思源或禁用/启用插件后生效。

## 注意

- 日记识别依赖文档路径以 `YYYY-MM-DD` 结尾；当前日记路径 `日记/YYYY/MM/YYYY-MM-DD` 可直接使用。
- 习惯嵌入块是 JS 查询嵌入块，需要关闭安全模式。
- 多步任务请使用嵌套任务列表；普通段落按单步任务处理。
